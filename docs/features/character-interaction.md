# Karakter dönüşü

Backlog. Mevcut CRT sahnesi ve artwork korunur. İleride sürüklemeyle 360 derece dönüş, durunca dinlenme görünümüne yumuşak dönüş ve kısa şaşı göz etkileşimi değerlendirilecek.

Tek rasterı CSS ile döndürmeyi gerçek 3B dönüş diye sunma; uygun çok-açılı/katmanlı/3B asset gerekir. Dokunma, klavye, reduce-motion ve normal sayfa scroll’u korunur. Asset/runtime seçimi işi alınırken yapılır.
