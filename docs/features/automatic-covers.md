# Görsel kütüphanesi ve kapaklar

Dış sağlayıcı/Pexels araması şimdilik kullanılmayacak. Mevcut elle görsel yükleme/seçme ve görselli kartlar korunur; uygulamadaki eski arama Mac’te sadeleştirilecek.

Backlog hedefi siteye ait görsel kütüphanesi: kullanıcı kütüphaneden seçebilir, yazı içeriğine göre görsel önerileri sunulabilir. Bu tek ana issue’da ele alınır; otomatik kapak için mükerrer issue açılmaz. Sessizce kapak atama/değiştirme kararı verilmedi.

Görsel erişimi, kaynak/lisans/atıf, boyut/tür sınırları ve geç yanıtların kullanıcı seçimini ezmemesi korunur. Yazı/seri ortak kapak modeli içerik kimliğinden ayrıdır; provider seçimi sonraki işte belirlenir.
