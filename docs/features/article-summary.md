# Yazı özeti

Özet ayrı metin alanı olarak korunur; gövde, tema veya URL ile birleşmez. Boş olabilir; mevcut DTO limitleri OpenAPI’dedir. İçerik kartı kısa özet gösterir, Tamamını oku kalıcı yazıya gider.

Studio’daki özet değişikliği yazının çalışma taslağına kaydedilir; yayındaki sürüm Yayımla’dan önce değişmez. Seri bölümünün gövde önizlemesi ayrı sunum olabilir. Otomatik AI özeti onaylı kapsam değildir.
