# Özel yazı kapsamı

Sahip için ayrı özel/kilitli yazı ürünü yeni kapsamdan çıkarıldı. Bu, taslakların public olması veya kullanıcı notlarının açılması anlamına gelmez.

Mac’te sadeleştirmede mevcut private kayıtları kendiliğinden yayımlama/silme. Yetkisiz API, URL, medya, SSR, sitemap ve cache erişimlerini koru; eski kayıt geçişi gerçek veri kontrolüyle ele alınır. Draft/scheduled/archive/trash görünürlük koruması sürer. Gelecek üye yazarlığı bu özellik için otomatik karar değildir.
